# ElevanceSkills-GenAI-Text-to-Image-Generator
# Real-Time Text-to-Image Generator using Stable Diffusion

## Overview

This project implements a Real-Time Text-to-Image Generator using Stable Diffusion and Hugging Face Diffusers. The system converts natural language prompts into AI-generated images through text preprocessing, text embeddings, attention mechanisms, and conditional image generation.

Developed as part of the ElevanceSkills Data Science & Generative AI Internship Program.

## Project Objectives

- Generate images from natural language text prompts.
- Understand Stable Diffusion architecture.
- Explore text embeddings and tokenization.
- Analyze self-attention and cross-attention mechanisms.
- Build a complete text-to-image generation pipeline.
- Validate and test image generation outputs.

## Results

The project successfully generates images from natural language prompts using Stable Diffusion.

Sample outputs were generated and validated using multiple test prompts including:

- Sports Car on a Mountain Road
- Futuristic Robot Reading a Book
- Tropical Beach at Sunrise
- Cat on a Wall
- Astronaut on Mars

The pipeline successfully completed all validation tests.
